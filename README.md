# 🔥 JMS OS

**JMS OS** is my custom embedded networking system and firmware ecosystem.

It brings together hardware support, networking, diagnostics, recovery, management, and custom system behavior under one platform.

```text
                JMS OS
                   │
       ┌───────────┼───────────┐
       │           │           │
   Hardware     Firmware    Networking
       │           │           │
       └───────────┼───────────┘
                   │
              JMS Services
                   │
          Diagnostics & Tools
```

JMS OS projects can be built on different hardware and software foundations depending on the target device.

That may include:

`OpenWrt` • `Realtek SDK` • `Embedded Linux` • custom bootloaders and system components.
